# 용어집

프로젝트의 도메인 용어를 정리하는 문서다.
같은 개념을 여러 이름으로 부르지 않기 위해, 새 개념이 생기면 바로 추가한다.

## 공통

| 용어 (한글) | 영문 명칭 | 정의                   | 비고                             |
| ----------- | --------- | ---------------------- | -------------------------------- |
| 회원(예시)  | `User`    | 서비스에 가입한 사용자 | `Member`, `Account` 등 혼용 금지 |
| 카테고리    | `Category` | 장소를 종류별로 나누는 분류 (전시, 팝업 등) | 동네는 카테고리가 아니다 (`Neighborhood`) |
| 장소        | `Place`   | 사용자에게 추천하는 들를 곳 (팝업, 전시 등) | 카테고리 1개에 속한다 |
| 장소 상태   | `PlaceStatus` | 장소의 운영 단계: `SCHEDULED`(오픈 예정), `ACTIVE`(운영 중), `INACTIVE`(종료), `PENDING`(승인 대기) | 서비스에는 `ACTIVE`만 노출한다. `PENDING`은 일반 어드민 계정이 등록을 요청한 상태로, 슈퍼 계정이 승인한다 |
| 상태 전환 방식 | `StatusChangeType` | 장소 상태를 바꾸는 방식: `AUTO`(시작일·종료일에 따라 자동), `MANUAL`(어드민이 직접) | |
| 요일 코드   | `DayOfWeekCode` | 영업시간의 요일: `MON`~`SUN` | `java.time.DayOfWeek`(`MONDAY`…)와 다른 타입이다. 필드·컬럼 이름은 `dayOfWeek`/`day_of_week` |
| 일정 타입   | `ScheduleType` | 장소의 운영 기간 구분: `PERIOD`(기간제), `ALWAYS`(상시) | `PERIOD`만 시작일·종료일이 있다 |
| 영업시간    | `OperatingHour` | 장소의 요일별 오픈·마감 시간 | `is_day_off`는 그 요일이 휴무일인지를 뜻한다. 마감이 오픈보다 이르면 다음날 마감, 둘 다 `00:00`이면 24시간 영업 |
| 키워드      | `Keyword` | 장소의 특징을 나타내는 태그 (가족과함께 등) | 공통 목록에서 장소마다 여러 개를 고른다 |
|             |           |                        |                                  |
